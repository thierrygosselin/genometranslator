# Dot-keepers for read_vcf

Return the set of `...` arguments supported by
[`read_vcf()`](https://thierrygosselin.github.io/genometranslator/reference/read_vcf.md).
This builds on the global core keepers and adds/removes any
read_vcf-specific arguments.

## Usage

``` r
dots_keepers_read_vcf(extra = NULL, exclude = NULL)
```

## Arguments

- extra:

  Default: `extra = NULL`.

- exclude:

  Default: `exclude = NULL`.
