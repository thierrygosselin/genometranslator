# summary_gds

Summary of gds object or file: number of samples and markers

## Usage

``` r
summary_gds(gds, check.sync = FALSE, verbose = TRUE)
```

## Arguments

- gds:

  A genome GDS file path or object. Default: `gds = NULL`.

- check.sync:

  (logical, optional) Check if GDS object is in sync with radiator
  metada. Default: `check.sync = FALSE`.

- verbose:

  Logical indicating whether progress messages are emitted. Default:
  `verbose = TRUE`.
