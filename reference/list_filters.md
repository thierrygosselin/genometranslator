# List current active filters (individuals and markers) in radiator GDS object.

List current active filters (individuals and markers) in radiator GDS
object.

## Usage

``` r
list_filters(gds)
```

## Arguments

- gds:

  A genome GDS file path or object. Default: `gds = NULL`.

## See also

[`sync_gds`](https://thierrygosselin.github.io/genometranslator/reference/sync_gds.md),
`list_filters`.
