# update_bl_markers

Generate and update blacklist of markers on radiator GDS node

## Usage

``` r
update_bl_markers(
  gds,
  generate = FALSE,
  update = NULL,
  extract = FALSE,
  bl.gds = NULL
)
```

## Arguments

- generate:

  Default: `generate = FALSE`.

- update:

  Default: `update = NULL`.

- extract:

  Default: `extract = FALSE`.

- bl.gds:

  Default: `bl.gds = NULL`.
