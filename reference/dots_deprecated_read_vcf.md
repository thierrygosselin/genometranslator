# Deprecated dot-arguments for read_vcf

Return the set of deprecated `...` arguments understood by
[`read_vcf()`](https://thierrygosselin.github.io/genometranslator/reference/read_vcf.md).
Currently this is just the global deprecated set, but the helper allows
you to add read_vcf-specific deprecated args later if needed.

## Usage

``` r
dots_deprecated_read_vcf(extra = NULL, exclude = NULL)
```

## Arguments

- extra:

  Default: `extra = NULL`.

- exclude:

  Default: `exclude = NULL`.
