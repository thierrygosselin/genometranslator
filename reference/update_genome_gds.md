# update_genome_gds

Update a genome GDS metadata node

## Usage

``` r
update_genome_gds(
  gds,
  metadata.node = TRUE,
  node.name,
  value,
  replace = TRUE,
  sync = FALSE,
  summary = FALSE,
  verbose = FALSE
)
```

## Arguments

- metadata.node:

  Default: `metadata.node = TRUE`.

- replace:

  Default: `replace = TRUE`.

- sync:

  Default: `sync = FALSE`.

- summary:

  Default: `summary = FALSE`.

- verbose:

  Default: `verbose = FALSE`.
