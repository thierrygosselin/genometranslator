# Summarise genomic data dimensions

Summarise genomic data dimensions

## Usage

``` r
genome_info(x, verbose = FALSE)
```

## Arguments

- x:

  A tidy genomic data frame or supported GDS object.

- verbose:

  Display the summary.

  Default: `verbose = FALSE`.

## Value

A list containing counts of chromosomes, loci, markers, strata, and
individuals.
