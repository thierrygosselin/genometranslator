# Genome GDS constructor

helper function to construct a genome GDS

## Usage

``` r
genome_gds(
  genotypes = NULL,
  biallelic = TRUE,
  data.source = NULL,
  strata = NULL,
  markers.meta = NULL,
  genotypes.meta = NULL,
  dp = NULL,
  ad = NULL,
  gl = NULL,
  filename = NULL,
  open = FALSE,
  verbose = TRUE
)
```

## Arguments

- genotypes:

  Default: `genotypes = NULL`.

- biallelic:

  Default: `biallelic = TRUE`.

- data.source:

  Default: `data.source = NULL`.

- strata:

  Default: `strata = NULL`.

- markers.meta:

  Default: `markers.meta = NULL`.

- genotypes.meta:

  Default: `genotypes.meta = NULL`.

- dp:

  Default: `dp = NULL`.

- ad:

  Default: `ad = NULL`.

- gl:

  Default: `gl = NULL`.

- filename:

  Default: `filename = NULL`.

- open:

  Default: `open = FALSE`.

- verbose:

  Default: `verbose = TRUE`.
