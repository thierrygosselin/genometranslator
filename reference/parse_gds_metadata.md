# parse_gds_metadata

function to parse the format field and tidy the results of VCF

## Usage

``` r
parse_gds_metadata(x, gds = NULL, verbose = TRUE, strip.rad = FALSE)
```

## Arguments

- gds:

  Default: `gds = NULL`.

- verbose:

  Default: `verbose = TRUE`.

- strip.rad:

  Default: `strip.rad = FALSE`.
