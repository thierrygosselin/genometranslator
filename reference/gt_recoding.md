# gt_recoding

Translate among supported genotype encodings.

## Usage

``` r
gt_recoding(
  x,
  gt = TRUE,
  alt.dosage = TRUE,
  gt.vcf = TRUE,
  gt.vcf.nuc = TRUE,
  arrange = TRUE
)
```

## Arguments

- gt:

  Default: `gt = TRUE`.

- alt.dosage:

  Default: `alt.dosage = TRUE`.

- gt.vcf:

  Default: `gt.vcf = TRUE`.

- gt.vcf.nuc:

  Default: `gt.vcf.nuc = TRUE`.

- arrange:

  Default: `arrange = TRUE`.
