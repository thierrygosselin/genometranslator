# update_bl_individuals

Generate and update blacklist of individuals on radiator GDS node

## Usage

``` r
update_bl_individuals(
  gds,
  generate = FALSE,
  update = NULL,
  extract = FALSE,
  bl.i.gds = NULL
)
```

## Arguments

- generate:

  Default: `generate = FALSE`.

- update:

  Default: `update = NULL`.

- extract:

  Default: `extract = FALSE`.

- bl.i.gds:

  Default: `bl.i.gds = NULL`.
