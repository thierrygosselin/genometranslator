# dart_genotyper

Normalization of DArT genotypes

## Usage

``` r
dart_genotyper(
  x,
  dart.check,
  markers.metadata = NULL,
  gt.vcf = FALSE,
  gt.vcf.nuc = FALSE,
  gt = FALSE
)
```

## Arguments

- markers.metadata:

  Default: `markers.metadata = NULL`.

- gt.vcf:

  Default: `gt.vcf = FALSE`.

- gt.vcf.nuc:

  Default: `gt.vcf.nuc = FALSE`.

- gt:

  Default: `gt = FALSE`.
